# StockLens 200 — 미국 시가총액 200개 기업 자동평가 (독립 앱)

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```

인터넷 연결이 필요합니다. Yahoo Finance 공개 시세와 Wikipedia S&P 500 구성 목록을 가져옵니다. Yahoo의 요청 제한/응답 필드 변경으로 일부 기업의 분석이 불가능할 수 있으며 해당 경우 **분석 불가**로 표시합니다. API 키 없이 유료 EPS 컨센서스 및 실시간 데이터 품질을 보장하지 않습니다.

## 구현 범위
- S&P 500 목록에서 미국 기업 후보를 가져와 시가총액 기준 200개 선택. 시장 전체 미국 상장기업 중 정확한 Top 200을 보장하는 공식 거래소 유니버스가 아니라는 점을 명시합니다. 후보에서 누락되는 비-S&P500 미국 기업이 있을 수 있습니다.
- 최신 가격/재무 기반 자동 적정가 산출 (가용 데이터에 따라서 EPS 또는 FCF 기반). 사용자가 EPS/PER 입력 불가. 데이터 미확보 시 '판단 불가'.
- 단기 신호 4종(EMA20 Crossback, RSI 회복, 20일 돌파, 추세 되돌림)을 동일 방식으로 백테스트하고, 미래구간 검증 점수로 하나를 선택. 신호 승률은 보장된 확률이 아닙니다.
- 거래비용 왕복 0.2% 가정, 10거래일 보유, 신호 다음 날 종가 진입 및 10일째 종가 청산(단순화; 실제 체결/슬리피지와 다름). 동시 신호 중복·생존자 편향·과거 EPS 빈티지 누락 등 한계를 표시합니다.
- Streamlit `st.cache_data` 기반 자동 갱신. 앱이 켜져 있을 때만 갱신되며 백그라운드 상시 서버나 푸시 알림은 포함되지 않습니다.

## 운영형 전환에 필요한 것
1. 시총 전수조사 데이터 공급자 (미국 전체 상장사), 2. 회계연도별 GAAP/조정 EPS 컨센서스 및 변경 이력 유료 피드, 3. SEC 공시와 뉴스 이벤트 파이프라인, 4. point-in-time 과거 유니버스/가격/컨센서스, 5. 스케줄러/DB/웹호스팅, 6. 키움/텔레그램 등 알림 연동.
