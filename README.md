# StockLens 200 v2

미국 거래소 상장기업 전체에서 시가총액 상위 200개 **기업**을 매일 선정하고, 저장된 결과만 빠르게 보여 주는 Streamlit 대시보드입니다.

## 현재 완료 범위: v2 1단계

- Yahoo 거래소 스크리너를 1차 공급원으로 사용합니다.
- Nasdaq 미국 상장증권 전체 스크리너를 독립 백업으로 사용합니다.
- ETF, ETN, 펀드, 워런트, 권리, 유닛, 우선주, 채권을 제외합니다.
- Alphabet처럼 복수 주식 클래스가 있는 회사는 거래량이 큰 대표 티커 하나만 유지합니다.
- 양 공급원이 실패하면 검증된 마지막 정상 `data/universe.csv`를 사용합니다.
- 403, 429, 5xx와 네트워크 오류는 지수 백오프로 최대 3회 재시도합니다.
- yfinance 호출은 60초 제한 subprocess에서 실행해 전체 작업이 무기한 멈추지 않게 합니다.
- Streamlit은 외부 API를 호출하지 않고 저장 스냅샷만 읽습니다.
- GitHub Actions는 미국 정규장 마감 후인 평일 23:15 UTC에 갱신·테스트·커밋합니다.

23:15 UTC는 미국 동부 서머타임(EDT)에는 19:15, 표준시(EST)에는 18:15이므로 두 경우 모두 16:00 정규장 마감 이후입니다. 현재 단계에서는 미국 거래소 휴장일 캘린더를 별도로 연동하지 않아 평일 휴장일에도 작업은 실행됩니다. 이때 공급원이 반환하는 `market_data_as_of_utc`는 직전 거래일로 유지되며 앱은 수집 실행 시각이 아니라 이 실제 시장 데이터 기준시각을 표시합니다.

`engine.py`의 기존 적정가/신호 코드는 프로토타입 참고용이며 v2 앱에 연결되어 있지 않습니다. 재무 데이터의 시점 일관성, QQQ 벤치마크, 워크포워드 검증이 끝나기 전까지 정상 기능으로 표시하지 않습니다.

## 로컬 실행

```bash
python -m pip install -r requirements.txt
python scripts/update_data.py
streamlit run app.py
```

테스트:

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

## 데이터 파일

- `data/universe.csv`: 순위, 티커, 기업명, 가용한 섹터/국가, 시가총액, 최근가, 등락률, 공급원
- `data/status.json`: 실제 데이터 생성 시각, 공급원, 캐시 여부, 축약된 장애 상태

스냅샷 저장은 임시 파일 작성 후 교체하는 원자적 방식입니다. 200개 미만, 중복 기업, 비정상 순위, 음수/누락 시가총액이면 새 스냅샷으로 인정하지 않습니다.

## 무료 운영 구조

```text
Yahoo 거래소 시장 ─┐
                   ├─ 재시도 → 필터/중복제거 → Top 200 검증 → CSV/JSON
Nasdaq 전체 백업  ─┘                                      │
              실패 시 ← 마지막 정상 캐시                 ▼
                                                Streamlit 읽기 전용 표시
```

하루 한 번 15분 제한의 단일 Actions 작업과 작은 CSV 두 개만 사용합니다. API 키가 필요 없으며 `.streamlit/secrets.toml`은 Git에서 제외됩니다. 향후 키가 필요한 공급원을 추가할 때는 GitHub Actions Secrets와 Streamlit Secrets만 사용하고 값이나 응답 본문을 로그에 기록하지 않아야 합니다.

## 다음 단계(아직 미완료)

1. SEC 재무 원천과 보조 공급원을 이용한 EPS·실적·FCF·성장률·PER 교차검증
2. 보수/기본/낙관 적정가, 저평가율, 자동 매수 유리 구간, 신뢰도와 근거의 날짜별 저장
3. 가격 이력의 point-in-time 저장과 EMA Crossback, 돌파, 눌림목, RSI 회복 워크포워드 검증
4. 5/10/20거래일 승률·평균수익·손익비·최대낙폭·QQQ 초과수익 및 최소 표본 게이트
5. 검증 통과 신호만 상단에 표시하고 모바일 카드형 기록 화면 제공

## 데이터 한계

무료 공급원의 시가총액, 가격, 기업 분류는 지연되거나 정정될 수 있습니다. 미국 거래소 상장 여부와 기업 소재국은 서로 다른 개념이므로 해외 기업의 ADR도 포함될 수 있습니다. 이 프로젝트는 연구용이며 투자 권유가 아닙니다.
