# 3단계 단기 신호 검증 보고서

## 구현 범위

고정 규칙 네 가지를 비교한다.

- EMA Crossback: 장기 상승 추세에서 종가가 EMA20을 다시 상향 돌파
- 추세 돌파: EMA50 > EMA200인 상태에서 직전 20일 고점과 평균 거래량 조건 돌파
- 눌림목 반등: 최근 EMA20 접촉 뒤 양봉·직전 고점 회복·RSI 조건 충족
- RSI 회복: 장기 상승 추세에서 RSI(14)가 40을 상향 회복

각 신호는 5·10·20거래일 뒤 성과를 계산한다. 출력은 승률, 평균·중앙 수익률, 손익비,
청산거래 기준 낙폭, 일별 종가 기준 MTM 최대낙폭, MAE·MFE, 진입 갭, 같은 진입·청산일의
QQQ 수익률, QQQ 대비 초과수익 및 95% 블록 부트스트랩 구간이다. 사용자가 지표 기간이나
통계 문턱을 조정하는 UI는 제공하지 않는다. MAE·MFE는 일봉의 저가·고가를 사용하므로
장중 체결 순서는 알 수 없다.

## 미래 정보 누출 방지

- 이동평균, RSI, 고점, 거래량은 신호일 종가까지의 값만 사용한다.
- 20일 고점과 평균 거래량은 `shift(1)` 후 계산해 신호일 값을 기준선에 섞지 않는다.
- 진입은 다음 거래일 시가로 미뤄 종가 신호를 같은 종가에 체결하지 않는다.
- 종목과 QQQ에 모두 존재하는 거래일만 사용한다.
- 공통 거래일의 마지막 20%는 모든 전략에 같은 날짜 경계를 적용하며 전략 선택과 개발
  기준 설정에 사용하지 않는 독립 확인 기간이다.
- 앞 80%에서 초기 학습과 최대 3개 순차 워크포워드 폴드로 반복 검증한다.
- 원형 이동 블록 부트스트랩과 의존성에 보수적인 Benjamini-Yekutieli FDR을 적용한다.
- 같은 종목·날짜의 전략 중복률과 섹터별 일일 신호 집중도를 별도 기록한다.

## 2026-10-12 실제 개발 검증

기준 Top 200 스냅샷의 시장 세션은 2026-10-09이다.

| 범위 | 이력 확보 | 백테스트 | 연구 후보 | 독립 통과 | 활성 신호 | 상태 |
|---|---:|---:|---:|---:|---:|---|
| 전체 200개 | 191/200 | 2,292 | 4 | 0 | 0 | degraded |

개선 전 LRCX EMA Crossback 10거래일은 70/30 분리의 마지막 11건에서 승률 81.82%,
평균수익 9.76%, QQQ 초과수익 7.73%였다. 새 구조에서는 공통 달력 독립 기간을
2025-07-30부터 고정했고, 총 36건을 개발학습 11건, 워크포워드 11건, 최종 독립 14건으로
분리했다. 최종 구간 방향은 승률 78.57%, 평균수익 10.32%, QQQ 초과수익 8.33%로
재현됐지만 총 80건·최종 20건과 개발학습 20건 기준에 미달한다. 또한 개발학습·워크포워드 초과수익과
워크포워드 블록 부트스트랩 하한 조건을 통과하지 못해 상태는
`data_insufficient`이며 연구 후보로도 승격하지 않았다.

LRCX 최종 14건의 청산거래 기준 최대낙폭은 -6.42%였으나 일별 MTM 최대낙폭은
-16.29%였다. 평균 MAE -4.28%, 평균 MFE 15.11%, 최악의 다음 날 진입 갭은 -5.93%였다.
0.2% 기본비용 평균수익은 10.32%, 0.6% 비용 스트레스 평균수익은 9.88%였다. 작은 표본의
관찰값일 뿐 확정된 매매 우위가 아니다.

최종 표본 문턱은 시드 20261012, 각 조건 300회 모의실험으로 점검했다. 영가설 수익률을
정규·두꺼운 꼬리·AR(1)·변동성 군집으로 만들었을 때 8건 표본의 단일전략 위양성률은
7.7~9.0%, 12건은 6.0~9.3%, 20건은 3.7~7.3%였다. AR(1)에서는 20건도 5%를 넘었으므로
20건만으로 충분하다고 주장하지 않으며, 전체 비교에 BY FDR과 개발 워크포워드 게이트를
추가 적용한다. 재현 명령은 `python scripts/calibrate_signal_samples.py`이다.

개발 구간만 통과한 연구 후보 4개는 AVGO EMA Crossback 10일, PLTR EMA Crossback 5일,
PWR EMA Crossback 5일·10일이었다. 어느 것도 최종 독립 신뢰구간과 비용 기준을 모두
통과하지 못했다.

191개 종목의 원시 규칙 발생일을 합친 결과 신호가 있었던 거래일은 1,291일이었다.
동일일 신호 종목은 최대 99개, 95백분위 67개로 시장 국면에 따라 강하게 몰렸다.
종목·날짜 기준으로 둘 이상의 전략이 겹친 비율은 28.16%, 하루 신호 중 가장 큰 섹터의
중앙 비중은 32.56%, 섹터별 일일 신호 수의 최대 절대 상관은 0.573이었다. 따라서 개별
신호의 표본을 서로 독립된 2,292개 실험처럼 해석할 수 없으며 BY 보정을 유지한다.

또한 현재 조정주가는 실행 시점에 내려받은 최신 조정계수를 사용한다. 이후 발생한 분할과
배당이 과거 계열을 다시 조정할 수 있으므로, 당시 알려진 조정계수를 날짜별로 보관하기
전까지 완전한 point-in-time 가격 데이터라고 주장하지 않는다.

이력을 확보하지 못한 9개 중 SPCX·SKHY·SNDK는 600거래일 최소 이력 미달이었고,
HSBC·HD·SHEL·BBVA·EQNR·GSK는 이번 실행의 Yahoo 응답에서 검증 가능한 최신 이력을
얻지 못했다. 누락값은 채우지 않았으며 이 종목들은 계산에서 제외했다.

## 실행 방법

개발 검증용 실행은 다음과 같다. 원시 이력 캐시는 Git에서 제외된다.

```powershell
python scripts/update_signals.py --allow-partial
python scripts/validate_signals.py --allow-partial
python -m pytest -q
```

동일 시장 세션의 검증 캐시로 코드 변경 후 통계만 재현할 때는 공급원을 호출하지 않는
`python scripts/update_signals.py --allow-partial --cache-only`를 사용한다. 캐시 기준일이
다르면 거부되며, 캐시가 없는 종목은 `verified_cache_unavailable`로 보류된다.

현재 소스 약관 검토가 끝나지 않았으므로 이 명령을 GitHub 예약 운영 작업에는 연결하지
않았다. `signal_status.json`의 `data_state`, `universe_bias_state`, `limitations`를 함께
읽어야 하며, 결과 CSV만 떼어 정상 운영 신호로 표시해서는 안 된다.

무료 대체 공급원 검토 결과는 [`market-data-source-review.md`](market-data-source-review.md)에
기록했다. 공개 대시보드 재배포까지 명시적으로 허용된 무료 API는 아직 확정하지 못했다.
